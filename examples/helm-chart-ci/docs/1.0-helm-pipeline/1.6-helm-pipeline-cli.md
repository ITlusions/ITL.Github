# helm-ci CLI

**Source:** `.github/scripts/helm-pipeline/src/helm_pipeline/`

The `helm-ci` package provides two console scripts used by the workflows. Install it from git:

```bash
python -m pip install "helm-ci @ git+https://github.com/ITlusions/ITL.Github.git@main"
```

## chart-pipeline

Implemented in `chart_pipeline.py`.

| Command | Purpose |
|---|---|
| `changed [--base SHA] [--all] [--chart NAME] [--tag TAG]` | Lists changed charts (used by the pipeline) |
| `setup-tools --directory DIR` | Downloads and verifies `kind` and `kubectl` |
| `setup-kind --directory DIR` | Sets up kind tooling |
| `lint-all` | Lints all charts |
| `check-requirements` | Checks requirements |
| `validate [CHART]` | Validates a chart |
| `check-version [CHART]` | Checks the chart version |
| `render-diff [CHART] [BASE]` | Renders and diffs a chart against a base revision |
| `package [CHART] [--destination DIR]` | Packages a chart (default `dist/packages`) |
| `publish [CHART]` | Publishes a chart |

## security-scan

Implemented in `security_scan.py`.

| Command | Purpose |
|---|---|
| `setup-tools --directory DIR --tool {trivy,gitleaks}` | Downloads and verifies scanner binaries (repeatable `--tool`) |
| `chart [CHART]` | Renders and scans a chart with Trivy |
| `repository` | Scans the repository |
| `secrets [--base REV]` | Scans for secrets with gitleaks, optionally only commits after `REV` |
| `dependencies` | Scans dependencies |

Failed scanners are recorded in `scan-errors.json` inside the report directory.
