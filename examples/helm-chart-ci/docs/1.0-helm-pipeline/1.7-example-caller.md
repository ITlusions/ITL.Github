# Example caller

**File:** `examples/helm-chart-ci/helm-chart-ci.yml`

Calls the [pipeline](1.2-pipeline-workflow.md) on pushes to `develop` and `feature/**`, on pull requests to `develop`, and on a weekly schedule (`0 3 * * 1`).

## Manual run

`workflow_dispatch` accepts two inputs:

| Input | Type | Effect |
|---|---|---|
| `full-scan` | boolean | Tests every chart and the scheduled Kubernetes versions |
| `chart` | string | Tests only `charts/<chart>` |

Concurrency group: `helm-ci-${{ github.ref }}`.

## Usage in another repository

```yaml
jobs:
  pipeline:
    uses: ITlusions/ITL.Github/.github/workflows/_reusable-helm-pipeline.yml@main
    with:
      full-scan: ${{ github.event_name == 'schedule' }}
      chart: ${{ inputs.chart || '' }}
```

Reusable workflows are referenced at `@main`, so changes take effect in callers only after they are pushed.
